# Consulta Automática de CPF

## Instalação

```bash
pip install -r requisitos.txt
```

## Execução

```bash
python consulta.py
```

## Passos

1. Escolha a planilha.
2. Faça login no sistema.
3. Clique em "Por Documento".
4. Pressione ENTER no terminal.
5. Aguarde o término da consulta.

Será criado automaticamente um arquivo chamado:

NOME_DA_PLANILHA_RESULTADO.xlsx
